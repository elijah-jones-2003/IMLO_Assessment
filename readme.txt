To run IMLO.py (the file containing my code) you will need Python 3.11
1. 'venv' should come preinstalled if not use: pip3 install venv
2. Create virtual environment at your chosen location: python<version> -m venv <virtual-environment-name>
3. Activate environment: <virtual-environment-name>\Scripts\activate
4. Install torch : python -m pip install torch
5. Run IMLO.py
