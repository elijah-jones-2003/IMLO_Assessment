To run IMLO.py (the file that runs my model) you will need Python 3.11, pytorch 2.2 or newer and the flowers-102.pth file
1. 'venv' should come preinstalled if not use: pip3 install venv
2. Create virtual environment at the root directory: python<version> -m venv <virtual-environment-name>
3. Activate environment: <virtual-environment-name>\Scripts\activate
4. Install torch : python -m pip install torch
5. Run IMLO.py
